# Dosar

Aplicație desktop pentru pregătirea documentelor contabile pentru SAGA.

[Descarcă ultima versiune](https://github.com/vladblaj/dosar-releases/releases/latest)

Acest repository conține numai instalatoare, sume de control și metadate pentru actualizări. Codul sursă este privat.

Windows: descarcă `Dosar Setup <versiune>.exe` și urmează instalarea. Instalatorul nu este încă semnat digital. Versiunile vechi, fără actualizare automată, necesită o instalare manuală inițială.

Documentele și setările sunt păstrate local, separat de aplicație. Actualizările sunt descărcate din acest repository; repornirea se face la cerere.

Pachetele macOS cu actualizare automată vor fi disponibile după configurarea semnării Developer ID și a notarizării.
